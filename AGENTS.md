# Portfólio profissional

- Trabalhe somente neste repositório e consulte `DESIGN_SYSTEM.md` antes de alterar a interface.
- Execute as etapas do roadmap do usuário em ordem. Pare após cada etapa para commit e push manuais; não execute `git add`, `git commit`, `git push` nem alterações de branch.
- Não invente experiência, resultados, contatos, domínio, fotografia ou links de demonstração.
- Next.js App Router, TypeScript strict, Tailwind CSS e Prettier são a base. Prefira componentes simples e acessíveis.
- O conhecimento da fábrica está em `../../recursos/knowledge-base/INDEX.md`; consulte somente padrões ligados à tarefa. Histórico não prova validação atual.
- Faça `typecheck`, `lint`, `format:check` e `build` quando pertinentes; registre resultados reais. Não publique sem autorização.
