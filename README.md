# Portfólio profissional

Projeto em oito etapas. A Etapa 01 estabelece Next.js, Tailwind, TypeScript, Prettier e os tokens visuais. O conteúdo e as seções do portfólio entram nas etapas seguintes.

```bash
npm install
npm run dev
```

Direção visual e decisões: [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md). O domínio, as informações profissionais e os contatos públicos ainda serão definidos antes da publicação.
